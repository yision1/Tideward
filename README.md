# Tideward

Tideward is an open-source third-party launcher developed to address the shortcomings of the Wuthering Waves Launcher. It aims to completely replace the official launcher. In addition to the basic functions of a launcher, I will add extra features based on my own needs, such as:

- Record game time
- Switch game accounts
- View game screenshots
- Save gacha records
- Switch game servers

More features are left for you to explore.

## Installation

First, your device needs to meet the following requirements:

- Windows 10 1809 (17763) or later
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2) installed
- [WebP Image Extension](https://apps.microsoft.com/detail/9pg2dk419drg) installed
- For a better experience, enable **Transparency effects** and **Animation effects** in the system settings

> [WebP Image Extension](https://apps.microsoft.com/detail/9pg2dk419drg) is usually included with Windows. If the application cannot display background images correctly, check that it is installed.

Then download the archive for your CPU architecture from [GitHub Releases](https://github.com/yision1/Tideward/releases), extract it, run `Tideward.exe`, and follow the prompts.

## Development

To compile the application locally, install Visual Studio 2022 and select the following workloads:

- .NET desktop development
- Desktop development with C++
- Universal Windows Platform development
